# SemMan4Cat

**SemMan4Cat** is a semantic workspace for managing, exploring, querying, and sharing research metadata and knowledge graphs.

SemMan4Cat is developed within **NFDI4Cat** and supports working with RDF-based research data through datasets, named graphs, SPARQL queries, graph exploration, and controlled sharing.

## Try SemMan4Cat

SemMan4Cat is available at:
https://semman4cat.nfdi4cat.org/

## Feedback and Issues

This repository is currently used as the public issue tracker for SemMan4Cat.

If you encounter a problem, have an idea for a new feature, or would like to suggest an improvement, please open an issue.

- **Bug report** — something does not work as expected
- **Feature request** — suggest new functionality or an improvement

Feedback from users and developers of other NFDI4Cat services is very welcome.

## About

SemMan4Cat is developed at the High-Performance Computing Center Stuttgart (HLRS), University of Stuttgart, within NFDI4Cat.
